# Hi, I'm Alex

Software engineer at [Solea Energy](https://solea.energy), working on the platform
our traders submit power trades through. Most of my week is Go on the backend and
React with TypeScript on the frontend, and I like the work best when I own both
halves of a feature.

## Side projects

- [Portfolio](https://github.com/alcash55/Portfolio), this site. React and
  TypeScript on the front end, Go and Gin on the back end, deployed
  independently to GitHub Pages and Render. Six themes measured for WCAG
  contrast rather than eyeballed, 178 unit tests plus a Playwright suite
  gating every deploy, and a projects API with a one-hour cache and
  single-flight refresh that serves stale data with an honest notice when
  GitHub is unreachable.
- [Little-Town](https://github.com/alcash55/Little-Town), a web app for
  running Old School RuneScape bingo competitions. React and TypeScript
  front end, Express and Supabase back end, and a Discord bot that ingests
  screenshot submissions straight from a Discord channel for tile
  completion review.
- [Royalty VS Code Theme](https://github.com/alcash55/Royalty-VS-Code-Theme),
  a color theme on the Visual Studio Marketplace. Version 3 replaced a
  background color that failed half the syntax palette against WCAG AA, and
  a script now checks all 174 color pairs and fails the build on any
  regression.
- [ac-composite-actions](https://github.com/alcash55/ac-composite-actions),
  reusable GitHub Actions composite actions. The diff action fixed a
  pagination bug that was silently truncating any pull request over 30
  files, and the ATS check action scores a resume PDF against an
  eight-category, 100-point rubric.
